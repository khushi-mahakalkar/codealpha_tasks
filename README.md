# 📌 Completed Projects

## 🕵️ Task 1 — Code Detective

**Folder:** `Task1_Hangman`

Code Detective is a programming-themed Hangman game created as a console-based Python application.

The player has to discover a secret programming-related word by guessing letters. To make the game more interesting, it provides clues and keeps track of the player's performance.

### Features

- Random selection of a secret word
- Programming-related vocabulary
- Progressive clues to help the player
- Limited number of incorrect guesses
- Previously guessed letter tracking
- Score calculation
- Detective ranking system
- Option to play another case

### Concepts Practiced

- Lists
- Dictionaries
- Loops
- Conditional statements
- Random module
- User input
- String manipulation

**Main File:** `Task1_Hangman/hangman.py`

# 📈 Task 2 — Smart Portfolio Tracker

**Folder:** `Task2_StockPortfolio`

Smart Portfolio Tracker is a simple investment calculator developed to practice working with dictionaries, calculations, user input, and file handling.

The program provides a predefined list of stocks and their prices. The user can select stocks, enter quantities, and receive a detailed summary of their investments.

### Features

- Displays available stocks and prices
- Accepts stock symbols from the user
- Accepts the quantity of shares
- Calculates individual investment values
- Calculates the total portfolio value
- Prevents duplicate stock entries
- Validates user input
- Handles invalid numeric input
- Generates an optional portfolio report

### Example Calculation

If a user selects:

`AAPL × 8 = $1440`

and:

`AMZN × 5 = $950`

the program calculates:

`Total Investment = $2390`

### Concepts Practiced

- Dictionaries
- Loops
- Arithmetic operations
- User input
- Conditional statements
- Exception handling
- File handling

**Main File:** `Task2_StockPortfolio/portfolio.py`
